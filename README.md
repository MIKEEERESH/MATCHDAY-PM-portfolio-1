# ⚽ MatchDay — Портфолио IT Project Manager

**Проект:** Официальное мобильное приложение футбольного клуба «Заря» для болельщиков.  
**Роль:** Project Manager  
**Команда:** 15 человек  
**Бюджет:** 20 млн рублей  
**Срок:** MVP за 5 месяцев, полный функционал — 7 месяцев  
**Цель:** Увеличить продажи билетов и мерча на 20% за сезон  

---

## 📋 Паспорт проекта

| Параметр | Значение |
|---|---|
| **Продукт** | Мобильное приложение «MatchDay» для болельщиков ФК «Заря» |
| **Бизнес-цель** | Рост продаж билетов и мерча на 20% в течение сезона |
| **PM проекта** | [Твоё Имя] |
| **Бюджет** | 20 000 000 ₽ |
| **Срок MVP** | 5 месяцев |

---

## ⚠️ Ключевые вызовы и конфузы на проекте

| № | Ситуация | Инструмент PM |
|---|---|---|
| 1 | CEO требует NFT-билеты без бюджета и сроков | Change Request |
| 2 | Билетный вендор задерживает API на 3 недели | RAID, эскалация |
| 3 | Tech Lead систематически завышает оценки | 1-1, ретроспектива |
| 4 | Увольняется единственный Android-разработчик | Risk Response, кросс-обучение |
| 5 | Видеохайлайты грузятся 10 секунд | Incident, CDN |
| 6 | PO и дизайнер предлагают фичи в обход бэклога | RICE, приоритизация |
| 7 | Платёжный шлюз не поддерживает рекуррентные платежи | RAID, план Б |
| 8 | Приложение падает за час до матча | Incident Response Plan |

---

## 📊 Ключевые метрики успеха (Target)

- Рост продаж билетов и мерча: **+20% за сезон**
- MAU через 3 месяца после запуска: **50 000**
- Время покупки билета: **≤ 30 секунд**
- Change Failure Rate: **< 10%**
- Time to Restore: **≤ 30 минут**
